# Toy Arena: Desk Clash — W0–1

## 1. Overview

国际桌面键鼠玩家；虚构家庭工作桌、无地域叙事，主角为原创机械玩具车，全部产品文字英文。短关卡 + 轻持久成长：单关计时预算45–60秒，期望单次尝试30–90秒，3关原型约3–6分钟（待真人测试）；当前熟练路径首关8.25秒/第二关25.77秒偏短，不能称时长目标达标。保存各关最高星数与设置；回访理由为改进路线和少受伤。驾驶 → 冲撞/跳台 → 完成目标 → 1–3 星 → 重试或下一关。没有账号、广告、内购、平台提交、社交。不是 Toy Rampage 或手机投掷游戏的移植。

首个动作承诺：按键立即移动，点击鼠标朝指针冲撞。首局：完成一条有坡道的竞速线路。原型不承诺十分钟内容；W2–3 扩展需真人验收后单独批准。

## 2. Visual Design

16:9 桌面俯视竞技场，800×450 为最小主验收，另测 907×510、1920×1080。木纹工作桌、胶带赛道、机械玩具的轮子与方向鼻明确。HUD 顶部，教学底部且不挡目标。DOM 菜单独立适配，画布固定坐标。无需触屏可玩；窄屏明确提示键鼠并保留菜单。

## 3. Game Mechanics

WASD/箭头为屏幕方向驾驶；加速度 680 单位/秒²，速度上限 250，摩擦每秒 4.8。鼠标左键向指针冲撞 520 速度、0.22 秒，冷却 1.1 秒；空格沿驾驶方向冲撞。坡道弹起 0.7 秒，空中越过障碍/避免伤害。撞墙反弹，纸块速度超过 160 或冲撞可碎。生命 3 次，受伤无敌 1.3 秒。

三关：Tape Sprint（60 秒内按顺序穿过 5 个门）；Stampede Station（60 秒内撞碎 8 个纸块，并在中央点停留累计 4 秒）；Marble Mayhem（45 秒生存且收集 4 个黄铜螺帽，滚珠每 1.5 秒生成、0.5 秒可见预告、滚速120，上限12）。每关 1 星=完成；2 星=竞速≤35秒、抢点≤40秒、生存无受伤之一；3 星=前两关零受伤、生存收集6螺帽。失败零星但保留历史最佳。先不实现完整零件商店，存档有版本、星数、声音和教学状态，W2–3 再做有取舍的零件。

三问合同：目标是当前关卡目标；反复驾驶与选择冲撞/坡道；门/碎块/螺帽产生进展，时间耗尽或生命归零失败。安全教学暂停关卡时钟与危险物，亲手驶过练习门，再点击撞碎练习块，最后进入真实挑战；可跳过、可重看，目标15–30秒。到30秒自动安全暂停，让玩家明确选择Start race/Keep practising；不强制开始或宣称学会。实际理解 unverified。

实验：陌生人是否在15秒内知道移动/能力/目标；是否能在30秒内造成进展；冲撞方向是否可预测；同三关是否有不同选择。未通过时停在原型，不扩内容。

## 4. Controls

WASD/方向键移动，鼠标瞄准、左键按下冲撞；Space 前冲；Esc/P 暂停，R 重试，M 静音。暂停、结果、菜单不接受游戏动作。失焦自动暂停，恢复需主动操作。顺序门始终标出下一门，接触后续错序门提示“Wrong order — Next: Gate N”1.5秒，不惩罚、不计进度。英文按钮可用键盘 Tab/Enter；菜单 Tutorial 重看。

## 5. Win / Lose Conditions

完成独立目标立即结算，展示逐颗星依据、用时与受伤数，Retry/Next/Arena 返回。时间/生命失败显示原因并立即重试。最高星只增不减，未知/损坏存档安全回退并提示；存储禁用仍可玩但提示无法保存。无排行榜与联网胜负。

## 6. Sound Effects

全部原创 WebAudio：96 BPM 8 小节循环合成旋律，三角波 220–660Hz 与低音110–165Hz，短包络；碰撞正弦180→70Hz/100ms，冲撞锯齿120→360Hz/120ms，奖励660→990Hz/180ms，成功C/E/G/高C各120ms，失败220→110Hz/350ms。音频需手势解锁，暂停/失焦停止，静音持久。最多12音符声部。商业安全且无外部音频。
