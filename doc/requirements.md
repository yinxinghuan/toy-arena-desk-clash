# Toy Arena: Desk Clash — W2–3

## 1. Overview

国际桌面键鼠玩家；虚构家庭工作桌，无地域叙事，原创机械玩具车，产品全英文。短关卡与持久成长：10张手工地图，单关30–90秒目标，计时预算45–90秒；熟练时长由真实键鼠QA报告，不用隐藏等待保证。星数、最快完成记录、零件配置与设置本地保存。回访理由是试不同配置、获取独立挑战星、解锁三个桌面主题。核心循环：驾驶→冲撞/跳台/推货→完成关卡→星数解锁→配置与重试。Sandbox不限时不记星，允许试全部零件。

已获用户W2–3批准；W0曾缺少的陌生真人理解证据仍缺，不能声称已补。原型历史结果仅在qa-w01保留。本轮不新仓、不迁到monorepo、不提交CrazyGames、不部署第二公开站点；无广告、账号、内购、联网、编辑器或剧情。不是Toy Rampage或移动投掷游戏换皮。

周计划删减：第一优先首两关时长/有取舍配置；第二10关骨架；第三星结果/Sandbox；第四真实许可音频；第五QA/变更日志。延期多人、账户、编辑器、故事、商店经济与未验证的额外内容，保核心碰撞、清楚目标与成长。

## 2. Visual Design

16:9固定俯视960×540，800×450主验收，另测640×360、907×510、1920×1080。Workshop木纹、Drafting冷色工作纸、Packing牛皮纸三桌主题；四轮玩具车、编号胶带门、纸块、带PUSH字货箱/虚线PACK接收框、ICE波纹区、红白移动挡板、坡道箭纹与滚珠预警。HUD顶部，机制短提示底部，菜单分屏内部滚动。键鼠优先，不宣称手机可玩。

## 3. Game Mechanics

公路胎加速度680/摩擦4.8，抓地胎800/6.8（急停但终速低），漂移胎600/3.3（更快滑行但难刹）。轻车架重量1/3生命；重车架1.8/4生命，20%更慢加速、80%更强推力。Ram模块冲撞速度520/冷却1.1s，E强化冲撞；Spring冲撞420/1.4s，E腾空0.7s/冷却3s。抓地/漂移/重车架/Spring分别3/6/4/5累计星解锁，星不消耗。独立搭配。坡道腾空0.7s，可越障免伤；生命用尽失败，伤后无敌1.3s。普通撞墙反弹不扣生命，滚珠接触扣生命，冲撞可摧毁滚珠。

关卡：Tape Sprint四圈20门/90s；Stampede Station两轮各8纸块、每轮5s抢点/90s，第二轮纸块与抢点换位；Marble Mayhem45s+4螺帽；Cargo Corner推两箱/75s；Ice Ribbon三圈+油滑区/90s；Nut Circuit50s+6螺帽+移动挡板；Moving Day推货+移动挡板/90s；Double Trouble两轮冲撞抢点+滚珠/90s；Packing Slalom三圈+移动挡板/90s；Last Desk Standing60s+6螺帽+油滑/挡板。滚珠1.5s生成、0.5s预警、速度120，上限12。

目标星=完成；速度星按关卡60/70/55/65/70/70/65s，生存技巧星=无受伤；额外星=竞速坡道两次、首抢点5s内连碎三块、首生存六螺帽、后段生存冲撞三滚珠，其他无受伤。独立星不强制逐层获得。前3关开放，后7关依次2/4/6/8/10/12/14累计星解锁。Sandbox无时钟失败/伤害/星数，暂停可试全零件，不把锁定测试配置写成竞技配置。

三问合同：目标=HUD/暂停页关卡目标；重复动作=驾驶并选择冲撞/坡道/主动能力；进展=门/碎块/抢点/螺帽/货箱，时间耗尽或生命归零失败。安全教程无时钟危险：亲手过练习门、点击撞碎纸块、然后真实首关；可跳过重看，30s安全暂停让玩家选择继续。理解仍comprehension unverified。

## 4. Controls

WASD/箭头驾驶，鼠标瞄准/左键按下冲撞，Space前冲，E主动能力，P/Esc暂停，R重试，M静音。菜单Tab/Enter，内部滚动列表Click，不抢滚动。失焦自动暂停，需手动恢复。不自制平台全屏，由宿主容器提供。

## 5. Win / Lose Conditions

顺序门、抢点、推货完成立即结算；生存等计时结束且螺帽足够。失败显示英文原因；Retry重置物理/计时，星数只增不减。结果逐项写Earned/Not earned与实际条件、用时、跳台次数、最佳连碎、新纪录、下一解锁。损坏/不可用存储英文提示，不阻断游玩。v2迁移旧三关最高星、静音、教学，不清空合法历史。

## 6. Sound Effects

替换实时振荡器占位：Abstraction/Tallbeard的Candy完整52.173787秒无缝循环（CC0，原文件），Kenney Impact Sounds碰撞/冲撞，Music Jingles进展/连碎/胜负/新纪录（CC0）。手势后异步读取解码，不阻塞驾驶；最多8短音声源+1背景，碰撞至少120ms间隔。主音量0–100%，默认65%；背景混合0.22，短音0.45/碰撞0.6。暂停/菜单停止全部声源，恢复一条背景，重试不叠加。静音音量持久，失败可无声继续。许可随public/dist交付并在设置署名；人工听感需真人验收。
